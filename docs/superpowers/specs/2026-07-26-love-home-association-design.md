# 昆明市大学生爱心家园协会官网设计规格

## 目标

为“昆明市大学生爱心家园协会”制作独立静态官网，并在社团列表中增加官网入口。页面需要突出“公益实践 + 就业成长”双主线，完整呈现现有材料，同时优先保证手机端体验。

## 视觉方向

采用已确认的“A. 温暖行动纪实”方向。红色爱心 Logo 作为品牌识别，多彩手印墙与真实活动照片承担主要视觉表达。整体为温暖、真实、克制的公益纪实风格，不采用夸张圆角、装饰性渐变球或过度卡片化布局。

## 页面结构

1. 固定导航栏：左侧返回社团列表，中间为 Logo 与协会名称，右侧为站内导航；手机端左侧为返回按钮、中央为 Logo 与简称、右侧为菜单按钮。
2. 全屏首页：使用手印墙照片，桌面与手机分别设置构图焦点。手机端使用动态视口高度，占满第一屏。
3. 协会简介：保留材料中的三段正文，并展示“1000+ 志愿者”“10000+ 服务群众”“实践育人 + 公益赋能”三项信息。
4. 部门组成：办公室、活动部、宣传部、人事部，保持提交内容原意。
5. 精彩瞬间：展示六张提交照片，使用纪实画廊并支持查看大图。
6. 品牌活动：完整展示三项活动。读书会按用户选择采用无图重点稿形式并保留新闻链接；其余两项使用对应现有照片。
7. 未来愿景：因无荣誉素材，不虚构荣誉墙，使用材料中的未来规划收束页面。
8. 页脚：协会名称、宗旨短句、返回社团列表入口。

## 响应式要求

- 包含 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`。
- 手机首屏使用 `min-height: 100vh` 与 `min-height: 100dvh`，导航高度计入布局。
- 375px、768px、1024px、1440px 无横向滚动。
- 手机横屏内容可读，菜单与固定控件不遮挡正文。
- 触控目标至少 44px，正文移动端不小于 16px。
- 手印墙无需要完整露出的正脸，手机裁切优先保留手印主体。

## 交互与可访问性

- 提供跳转正文链接、语义化标题层级、图片替代文本、键盘焦点样式。
- 手机菜单维护 `aria-expanded`，点击链接或按 Escape 后关闭。
- 图片灯箱可通过关闭按钮、背景点击和 Escape 退出。
- 返回顶部按钮滚动后出现。
- 遵守 `prefers-reduced-motion`。

## 内容约束

- 官网和列表名称统一为“昆明市大学生爱心家园协会”。
- 不大幅删减材料正文，不编造称号、荣誉或活动信息。
- 读书会不挪用其他活动照片。
- “助力环保，一倡百盒”沿用材料中的正式活动名称。

## 验证标准

- 自动检查页面文件、移动端元标签、导航结构、核心文案、图片引用和社团列表链接。
- 浏览器检查桌面端、375px 手机竖屏和手机横屏。
- 检查控制台错误、图片加载、菜单、灯箱、返回按钮和外部新闻链接。
